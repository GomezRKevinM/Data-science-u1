# Taller de Ciencia de datos 
_Unidad 1_

## 🧩 Ejercicios
### 🔹 Bloque 1: Datos estructurados vs. no estructurados
1. Crea una lista que represente datos estructurados (por ejemplo: edades de
estudiantes) y muestra su tipo de dato.
2. Crea una variable tipo texto que represente un comentario libre de un usuario
(dato no estructurado) y cuenta cuántas palabras tiene.
3. Crea un diccionario con información estructurada de un estudiante (nombre,
edad, carrera) e imprime cada valor por separado.

### 🔹 Bloque 2: Tipos de variables y sintaxis básica
1. Declara variables de tipo entero, flotante, cadena y booleano. Imprime el tipo de
cada una.
2. Escribe un programa que concatene nombre y apellido almacenados en variables.
3. Convierte una variable tipo string con valor numérico a entero y súmale 10.

### 🔹 Bloque 3: Operadores
1. Calcula el promedio de tres números usando operadores aritméticos.
2. Usa operadores de comparación para verificar si un número es mayor que 50.
3. Usa operadores lógicos para verificar si una persona es mayor de edad (≥18) y
4. tiene licencia.

### 🔹 Bloque 4: Estructuras de datos
1. Crea una lista con 5 frutas e imprime la tercera.
2. Añade un elemento a la lista anterior.
3. Crea una tupla con 3 ciudades y recórrela con un ciclo.
4. Crea un diccionario con productos y precios y muestra solo las claves.

### 🔹 Bloque 5: Control de flujo
1. Escribe un programa que determine si un número es par o impar.
2. Usa un ciclo for para imprimir números del 1 al 10.
3. Usa un ciclo while para contar regresivamente desde 5 hasta 1.
4. Crea una estructura condicional que clasifique una nota (A, B, C o D).

### 🔹 Bloque 6: Integración de conceptos
1. Crea una lista de 5 calificaciones, calcula el promedio y muestra si el estudiante aprueba (≥3.0).
2. Simula la lectura de datos desde una fuente (por ejemplo, una lista de nombres) e imprime cada uno en mayúsculas. 
3. Crea un pequeño programa que pida al usuario su edad y muestre un mensaje según su rango etario (niño, joven, adulto).
