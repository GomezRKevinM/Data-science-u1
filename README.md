## 🧩 Ejercicios
### 🔹1: Datos estructurados vs. no estructurados
1. Crea una lista que represente datos estructurados (por ejemplo: edades de
estudiantes) y muestra su tipo de dato. [Ver](/excercises/excercise1.py#L2-L7)
2. Crea una variable tipo texto que represente un comentario libre de un usuario
(dato no estructurado) y cuenta cuántas palabras tiene. [Ver](excercises/excercise1.py#L10-L17)
3. Crea un diccionario con información estructurada de un estudiante (nombre,
edad, carrera) e imprime cada valor por separado. [Ver](excercises/excercise1.py#L21-L44)

### 🔹2: Tipos de variables y sintaxis básica
1. Declara variables de tipo entero, flotante, cadena y booleano. Imprime el tipo de
cada una. [Ver](excercises/excercise2.py#L2-L25)
2. Escribe un programa que concatene nombre y apellido almacenados en variables. [Ver](excercises/excercise2.py#L28-L38)
3. Convierte una variable tipo string con valor numérico a entero y súmale 10. [Ver](excercises/excercise2.py#L41-L49)

### 🔹3: Operadores
1. Calcula el promedio de tres números usando operadores aritméticos. [Ver](excercises/excercise3.py#L5-L10)
2. Usa operadores de comparación para verificar si un número es mayor que 50. [Ver](excercises/excercise3.py#L13-L16)
3. Usa operadores lógicos para verificar si una persona es mayor de edad (≥18) y
4. tiene licencia. [Ver](excercises/excercise3.py#L19-L26)

### 🔹4: Estructuras de datos
1. Crea una lista con 5 frutas e imprime la tercera. [Ver](excercises/excercise4.py#L2-L3)
2. Añade un elemento a la lista anterior. [Ver](excercises/excercise4.py#L6-L7)
3. Crea una tupla con 3 ciudades y recórrela con un ciclo. [Ver](excercises/excercise4.py#L10-L12)
4. Crea un diccionario con productos y precios y muestra solo las claves. [Ver](excercises/excercise4.py#L15-L20)

### 🔹5: Control de flujo
1. Escribe un programa que determine si un número es par o impar. [Ver](excercises/excercise5.py#L2-L6)
2. Usa un ciclo for para imprimir números del 1 al 10. [Ver](excercises/excercise5.py#L9-L11)
3. Usa un ciclo while para contar regresivamente desde 5 hasta 1. [Ver](excercises/excercise5.py#L14-L18)
4. Crea una estructura condicional que clasifique una nota (A, B, C o D). [Ver](excercises/excercise5.py#L20-L37)

### 🔹6: Integración de conceptos
1. Crea una lista de 5 calificaciones, calcula el promedio y muestra si el estudiante aprueba (≥3.0). [Ver](excercises/excercise6.py#L3-L12)
2. Simula la lectura de datos desde una fuente (por ejemplo, una lista de nombres) e imprime cada uno en mayúsculas. [Ver](excercises/excercise6.py#L14-L21)
3. Crea un pequeño programa que pida al usuario su edad y muestre un mensaje según su rango etario (niño, joven, adulto). [Ver](excercises/excercise6.py#L24-L40)
